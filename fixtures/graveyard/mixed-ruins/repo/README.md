# mixed-ruins

A partly-ruined Python 3 project: some stones still stand. The code runs on a
modern interpreter and ships a license and a README, but it has no tests and no
continuous integration, so every change is a gamble.

## Usage

```
python app.py
```

Run the entrypoint to record a couple of ledger entries and print the running
total. There is no test suite yet; contributions that add one are welcome.

# Assets

Provenance and licensing notes for the visual and audio assets that ship with The Necro-Oracle. This document complements `docs/DISCLOSURES.md` and the asset-licensing table in `docs/COMPLIANCE.md`.

## Pixel-art arcana (visual)

The pixel-art arcana live in `apps/web/public/arcana/` as 15 committed lossless WebP images plus `manifest.json`. Every image was **AI-generated by the author** and then **converted to pixel art** (downscaled and quantized to a strict 4-shade palette). None of these images are third-party artwork; none are scans, photographs, or recolors of existing art.

- **Palette:** every arcana image uses only the fixed 4-shade phosphor set `#001a00`, `#0b4f1a`, `#2fa84a`, `#8cff9e`.
- **Format:** all images are committed as lossless WebP, so the pixels you see are exactly the pixels that were authored.
- **Rendering:** the application displays them with `image-rendering: pixelated` at integer scale and applies no colour-altering filter, so no additional processing changes the committed pixels at runtime.

### Art asset categories

Each disclosed category below is AI-generated by the author and then converted to pixel art.

1. **The 12 major-arcana diagnosis cards** (120×160 logical px each): `judgement`, `tower`, `devil`, `death`, `wheel`, `hermit`, `hanged_man`, `temperance`, `justice`, `moon`, `star`, `world`. AI-generated by the author, then converted to pixel art on the 4-shade palette. The header and footer rows are intentionally left blank so the application renders the Roman numeral, title, position, orientation, and diagnosis as CRT-font DOM text — that text is not part of the image.
2. **The Seer landscape** (256×144 logical px): the `seer` portrait shown on the boot/landing area. AI-generated by the author, then converted to pixel art on the 4-shade palette.
3. **The two Necronomicon frames**: `necronomicon-closed` (108×144 logical px) and `necronomicon-open` (256×144 logical px), used by the resurrection ritual. Both AI-generated by the author, then converted to pixel art on the 4-shade palette.

## Background theme (audio)

The `Background_Theme` is **original**. It is **synthesized in code at runtime** with the Web Audio API — square and triangle oscillators with simple arpeggios — and is composed deterministically from a seed. It uses **no external audio files, no audio samples**, and no melody copied from any existing game or song. There are no committed audio assets for the theme; the music exists only as code that generates it in the browser.

The peak output gain is capped at 0.2 on the normalized 0.0–1.0 scale, and the theme plays only after a user gesture while sound is on; it never plays during test or CI runs.
